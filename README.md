I’m excited to share my Mini Shell (msh) project, developed as part of my learning in Linux Internals. Mini Shell is a lightweight command-line interpreter written in C that replicates the core functionality of a Linux shell. Through this project, I explored key system-level concepts such as process management, signal handling, and inter-process communication using Linux system calls.

The shell supports execution of external commands using fork() and exec(), along with built-in commands like cd, pwd, and exit. It also includes advanced features such as background execution using &, job control (jobs, bg, fg), signal handling for Ctrl+C and Ctrl+Z, and support for special variables like $$, $?, and $SHELL. Additionally, it implements both single and multiple pipes for efficient communication between processes.

I also focused on robust command parsing, handling edge cases, and improving user interaction through a dynamic shell prompt. Error handling mechanisms were implemented to ensure smooth execution and better debugging. This project enhanced my problem-solving skills and gave me hands-on experience with real-time process coordination in a Linux environment, making it a strong foundation for advanced system programming.
